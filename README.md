After Dark is a Vice City cover studio: it turns your photos into GTA-style multi-panel cover art — neon-night, sunset, halftone and mono grades, five layouts, per-panel cropping — and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080. Everything runs offline in a desktop browser; photos never leave your machine.
## Run it
```sh
node serve.ts
```
